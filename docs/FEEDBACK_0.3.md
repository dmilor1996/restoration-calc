# Разбор замечаний по первой рабочей версии и принятые решения

Дата: 20.11.2026. Состояние: изменения в отдельной ветке, ожидают проверки на физическом устройстве.

## Установленные проблемы
1. «Сегодня», «Объекты» и «создание объекта» не отражают работу в мастерской.
2. Категория изделия чрезмерно заметна, хотя практически не влияет на технологии и расчёт.
3. Привязка существующего расчёта не объяснена.
4. В форме заказа показывается сырой текстовый редактор технологических этапов.
5. При старте автоматически начинается «Подготовка».
6. Ошибочное переключение этапа не отменяется.
7. «Начать новый выезд» не соответствует многодневной работе в мастерской.
8. В отчёте нет быстрого внесения дисков, лака и масла; оценка материалов не связана с расчётом.
9. «Точность расходов» и статус оплаты не помогают пользователю заполнить отчёт.
10. Почасовая ставка за 2 минуты выглядит как ошибка.
11. Калькулятор визуально выбивается из остальных пяти разделов, а типовой расчёт занимает слишком много действий.

## Сделано в ветке
- Навигация «Главная / Заказы / Мастерская / Прогресс / Калькулятор»; заголовок главной «В работе».
- Создание «Нового заказа», выбор «у клиента / в мастерской»; тип изделия убран под необязательные детали.
- Привязка ранее сохранённого расчёта объяснена; ссылка содержит плановую площадь, цену и нормативный расход покрытия, когда данные доступны.
- Нет обязательного редактора списка этапов перед созданием заказа: этапы выбираются на экране работы; собственную операцию можно добавить там же.
- Старт рабочей сессии запускает общий таймер «Общая работа», а не принудительную «Подготовку».
- Последнее ошибочное действие этапа/паузы/сушки можно отменить, при этом не удваивая отработанное время.
- Многодневные сессии обозначены рабочими днями; завершение дня не закрывает заказ.
- Появилась отдельная форма значимых расходников с нормами покрытия из связанного расчёта, количеством дисков и ценой за единицу. Это **пока записи в заказе**, не настоящее списание со склада.
- Финансы: полученная сумма, наличные/перевод/карта, тип заказчика, дополнительные траты. Статус ожидаемой оплаты исключён из новой формы, но сохранён в старом формате данных.
- Расчёт НПД: 4% при работе с физлицом, 6% с ИП/организацией, независимо от способа платежа. Налог ориентировочный; приложение не создаёт чеки.
- При записи менее 15 минут показывается предупреждение о непоказательной почасовой ставке.
- Вкладка «Калькулятор» работает внутри общей визуальной оболочки: быстрые прямоугольник/круг/известная площадь, лак/масло, текст для клиента и создание заказа; подробный калькулятор остаётся отдельным экраном.

## Не реализовано — осознанные ограничения
- Каталог «Мастерская» по-прежнему демонстрационный. Реальный склад, поступления, возвраты, остатки, покупные партии и единицы учёта нужно строить как отдельный модуль.
- Привязка расчёта на уровне данных пока только локальная, поэтому синхронизацию разных устройств нужно проектировать отдельно.
- Авторасход лака/масла — оценка из плановых норм, пока пользователь не введёт факт. Для заказа без площади / сохранённого расчёта оценка недоступна.
- Быстрый калькулятор покрывает типовые случаи; сложная геометрия, торцы, допуслуги, окрашивание и поездки остаются в подробном режиме со старой стилистикой.
- Налог приблизительный: не учитывается стартовый налоговый вычет и возможные особые условия, не формируется чек «Мой налог».
- Коррекция/удаление давних событий кроме последнего требует специального интерфейса редактирования хронологии; нынешняя кнопка «Отменить» предназначена для немедленных ошибок.
- Нельзя считать «после прямых расходов и НПД» полноценной чистой прибылью без общих накладных расходов и амортизации.
- Недостаточно браузерных тестов для гарантии идеальной работы на конкретном Android-устройстве: нужен APK и приёмка.

## Следующий этап
1. Испытать сборку с реальными данными; сделать экспорт резервной копии до установки.
2. Привести подробный калькулятор к единому дизайну и сократить заполнение стандартных операций без потери сложных возможностей.
3. Реализовать редактируемый каталог материалов и абразивов, быстрый выбор из склада в заказе, приход/расход/возврат и стоимость партий.
4. Добавить свободное исправление событий, фактическую и плановую площадь в карточке заказа и дополнительные способы быстрого учёта.
5. Разделить отчёт «выручка/прямые расходы/НПД/накладные расходы/час» и визуально маркировать полноту данных.
