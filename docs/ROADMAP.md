# План поэтапной разработки «Моя мастерская»
Версия: 0.1 · 19.11.2026

## P0. Основание проекта — текущий этап
- [x] Проверить фактическое разделение main и Android-ветки.
- [x] Зафиксировать видение, архитектурные ограничения, начальные сущности и порядок работы.
- [ ] Согласовать рабочее название и первый пользовательский сценарий.
- [ ] Проверить актуальную Android-сборку, релизный вход Google и обновление APK.
- [ ] Добавить проверки расчётов в CI, отдельные тестовые и стабильные сценарии.
- [ ] Спланировать резервное копирование и безопасную миграцию существующих данных.

**Результат:** документация и безопасный план изменений без нарушения действующего сайта.

## P1. Новый мобильный каркас
- [ ] Создать независимую мобильную точку входа, сохранив сайт в корне.
- [ ] Экран «Сегодня», навигация, тема, система UI-компонентов.
- [ ] Быстрый вход в калькулятор, объекты и активную сессию.
- [ ] Настроить сборку тестового APK из нового мобильного интерфейса.
- [ ] Проверить Android back, сон, перезапуск, офлайн, размеры экрана.

**Готово, когда:** можно установить APK и пройти навигацию без изменения опубликованного сайта.

## P2. Работа на объекте — первый завершённый бизнес-сценарий
- [ ] Карточка объекта, связанная со старым заказом/расчётом.
- [ ] Начало сессии, переключение этапов, пауза, завершение.
- [ ] Восстановление активной сессии при перезапуске и отсутствии сети.
- [ ] Короткие заметки, правка ошибочного времени.
- [ ] Итог по времени и доходности с прозрачным источником данных.
- [ ] Тесты двойного нажатия, смены даты, повторной синхронизации.

**Готово, когда:** можно реально провести полный выезд, не потеряв хронометраж.

## P3. Склад и инструменты
- [ ] Каталог инструмента и его карточки.
- [ ] Каталог материалов с единицами учёта и упаковками.
- [ ] Движения запасов (приход/расход/возврат/коррекция).
- [ ] Списание на конкретный объект и попадание в себестоимость.
- [ ] Минимальные остатки и список закупок.
- [ ] Позже — обслуживание, комплекты на выезд, история использования.

**Готово, когда:** остаток объясняется проводками, а расходы объекта совпадают со списаниями.

## P4. Прогресс и портфолио
- [ ] Месячные цели по доходу и занятости.
- [ ] Выручка, прямые затраты, прибыль и фактическая ставка в час.
- [ ] Достижения, основанные на проверяемых данных.
- [ ] Фото «до/после», портфолио, история развития.
- [ ] Индивидуальная настройка показателей и спокойные уведомления.

**Готово, когда:** показатели мотивируют, но не создают лишнего ввода.

## Приоритеты
P1 и P2 выше красивой аналитики: без реальной рабочей сессии нечего измерять. В P2 допускается ручной ввод расходов, до готовности P3. Фото и облачное файловое хранилище вводить только после проверки безопасности и резервного копирования.

## Качество и выпуск
- Каждая крупная функция — отдельная ветка/PR.
- Тесты прежде чем объединять изменения.
- Стабильное приложение устанавливается поверх предыдущей версии без потери данных.
- Перед изменением существующего облачного формата: экспорт, тест миграции, сценарий отката.
- Release APK подписывается постоянным ключом; тестовую сборку не выдавать за установленное обновление.

## Ближайшая техническая задача после P0
Создать отдельный Android UI shell (пока без склада и без переделки формул) с вкладками «Сегодня», «Объекты», «Мастерская», «Прогресс», доступом к текущему калькулятору и фиктивным объектом для проверки навигации. Это проверит архитектуру раньше, чем появятся реальные данные.
