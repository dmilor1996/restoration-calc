## Что доступно

- Публичный веб-калькулятор и старые расчёты; в Android также быстрый калькулятор на общем движке.
- Заказы у клиента и в мастерской, детали клиента, произвольные этапы, дни, таймеры, фактические материалы, финансы, статистика и резервные копии.
- Склад показывает демонстрационные позиции. Рабочие заказы хранятся локально в IndexedDB. Фотографии, отдельный справочник клиентов и синхронизация новых записей остаются направлениями развития.
- Путь на Windows: C:\Projects\restoration-calc. Готовый локальный APK: artifacts/apk/workshop-debug.apk. Начало сессии описано в AGENTS.md. Команды и восстановление — в docs/DEVELOPMENT.md.

## Известные ограничения и следующие проверки

- Прежняя ошибка «выберите тип работы» на этой ветке при создании и редактировании не воспроизвелась. Категория необязательна. Устаревший сценарий CI ссылался на экран «Объекты» и кнопки из PR №4; обновлён для PR №5.
- Android Lint выявил 23 предупреждения, ошибок 0. Они относятся к ресурсам, иконкам, версиям зависимостей и порядку элементов манифеста. Полный список находится в локальном отчёте Lint.
- У пробного изолированного эмулятора 36.1 при холодной загрузке падал системный графический процесс. Для ежедневной работы выбран отдельный Android 14 (API 34). Пользовательский Medium_Phone_API_36.1 доступен для самостоятельных задач.
- На физическом Galaxy S24+ текущая ветка ещё не принималась. Вход Google с release-подписью, обновление существующей установки на телефоне и реальные облачные данные в эту локальную проверку не входили.
- Локальный Git использует Git Credential Manager. Вход в GitHub восстановлен через браузер. Рабочая ветка отслеживает origin/work/windows-dev-environment. Инструкция для публикации — в docs/DEVELOPMENT.md.
- Следующая проверка перед выпуском — подписанный APK на Samsung, в том числе обновление поверх прежней версии, возврат и экспорт JSON. Дальнейшие продуктовые задачи перечислены в docs/ROADMAP.md.
