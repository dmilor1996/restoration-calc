# Реставрация — расчёт стоимости

Калькулятор стоимости реставрации деревянных поверхностей: вводите размеры — получаете площадь, цену за лак и масло-воск и готовый текст для клиента.

## Что умеет

- **Выбор разделов**: в расчёте участвуют «Поверхности», «Лестница» или оба блока — включаются плитками вверху страницы.
- **Формы**: прямоугольник, круг (по диаметру), трапеция (длина + две стороны или 4 разные грани), своя форма, известная площадь.
- **Своя форма** — редактор контура: заготовки (Г-, П-образная, со срезом, с вырезом…) или рисование по углам с нуля; углы перетаскиваются, длины сторон задаются точно в мм.
- **Торцы (кромка)**: толщина + выбор конкретных граней нажатием на схему. Невыбранные грани (у стены) не считаются.
- **Цены по диапазонам площади «от–до»** — отдельно для поверхностей и лестниц.
- **Правила цены**: минимальная разница между лаком и маслом, минимальная стоимость заказа, округление.
- **Ручная цена**: можно задать свою ставку за м² или свою итоговую цену.
- **Ночная работа**: коэффициент ×1,5–2.
- **Тексты для клиента** с подстановкой цен (`{лак}`, `{масло}`, `{площадь}`, `{раковина}`, `{плита}`), редактируются на вкладке «Тексты». Если указан телефон клиента — кнопка отправки в WhatsApp.
- **Заказы**: расчёт сохраняется целиком вместе с именем, телефоном, адресом и заметкой; его можно открыть, скопировать, позвонить клиенту или открыть адрес на карте.
- Светлая и тёмная тема, работает на телефоне и без интернета.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в репозиторий на GitHub.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка не нужна — это обычные HTML/CSS/JS файлы.

## Хранение данных

Сейчас цены, тексты и заказы сохраняются в браузере (localStorage). На вкладке «Цены» есть резервная копия в файл.

Для синхронизации между устройствами предусмотрен Firebase (Firestore + вход через Google). Чтобы включить:

1. Создать проект в [Firebase Console](https://console.firebase.google.com/), добавить веб-приложение.
2. Включить **Authentication → Google** и **Firestore Database**.
3. В **Authentication → Settings → Authorized domains** добавить `<логин>.github.io`.
4. Вставить конфигурацию в `js/firebase-config.js`.
5. Правила Firestore — доступ только владельцу:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
