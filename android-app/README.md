# Моя мастерская · объекты и выезды

«Сегодня», «Объекты» и «Прогресс» работают с личными записями на устройстве. «Мастерская» пока показывает примеры инструмента и расходников с отметкой «Демоданные».

## Проверка на телефоне

1. Из артефакта Restoration-apk распакуйте Restoration.apk. Откройте APK и выберите «Обновить», если установлена подписанная версия. При отказе Android сохраните прежнюю установку и данные.
2. В авиарежиме создайте объект. Для привязки существующего заказа раскройте «Клиент, выезд и расчёт».
3. Нажмите «Начать работу», выберите шлифовку, поставьте на паузу и перезапустите приложение. Откройте текущий объект на «Сегодня», продолжите этап и завершите выезд.
4. Начните новый выезд на этом же объекте. На этапе покрытия нажмите «Начать сушку», выберите уборку и завершите выезд. В истории доступны оба выезда, время активного труда, сушки и дороги.
5. Нажмите «Завершить заказ». Оставьте суммы пустыми и дополните их дома через «Внести суммы». В истории раскройте выезд для корректировки рабочего времени. Пропущенный выезд можно записать вручную.
6. В разделе «Объекты» откройте «Резервная копия». Сохраните JSON в выбранную папку. Импорт добавляет только отсутствующие объекты. Объекты с тем же ID пропускаются, при конфликте активных выездов или привязок импорт отменяется целиком. Копия содержит контактные данные и суммы в открытом виде.

## Хранение и расчёт

В mobile/work/ находятся модель и хранилище IndexedDB версии 1. Объект содержит UUID, ревизию, историю выездов и журнал событий с отдельными UUID и абсолютными отметками времени. Запись, проверка ревизии, уникальность открытого выезда и привязки к старому заказу защищены одной транзакцией. Экран показывает сохранённое состояние после успешной записи. Таймер пересчитывает длительность по отметкам и не требует фоновой службы. При ручной смене системных часов длительность можно исправить после выезда.

«Начать сушку» закрывает активный этап «Покрытие». Сушка может идти одновременно с уборкой и заканчивается вручную или вместе с выездом. Этап «Дорога» считается отдельно. Исправленная длительность заменяет сумму активных интервалов конкретного выезда. Исходная хронология сохраняется. Для ручных записей выбранная дата группирует работу по дню.

Оплата хранится в копейках как совокупная полученная сумма за заказ. Пустое поле означает неизвестное значение. Расходы могут быть примерными. Остаток после прямых расходов и соответствующая ставка за час вычисляются только при известных суммах. Сводка показывает охват по объектам. Личная база на этом устройстве отделена от входа в калькулятор.

Связь со старым заказом хранит ID и снимок отображаемой плановой цены при привязке. Калькулятор по-прежнему управляет своими черновиками, заказами, экспортом и Firebase. Копия выездов сохраняет ссылку, а сами старые расчёты экспортируются в калькуляторе. Новые объекты пока синхронизируются между устройствами только посредством ручного переноса отсутствующих записей. Для автоматической синхронизации предстоят правила доступа и разрешение конфликтов.

## Сборка

В android-app/ выполните npm ci, npm test и npm run sync. Для браузерных тестов нужен Chrome или Chromium, путь можно указать через CHROME_BIN. Gradle требует JDK 21 и Android SDK 35. Android APK в GitHub Actions проверяет расчёты и сценарий двух дней, собирает APK и устанавливает его на эмулятор Android 15. Package ID com.restoration.calc, прежние секреты подписи и схема versionCode сохраняются. Без ключа workflow выдаёт debug APK.
