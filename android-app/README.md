# Моя мастерская для Android

Приложение открывает «Сегодня». Четыре рабочих раздела показывают подписанные демонстрационные объекты, инвентарь и итоги. Кнопка «Калькулятор» открывает рабочие расчёты. Ссылка «Заказы калькулятора» ведёт к сохранённым заказам.

## Сборка и установка

При изменении Android-кода GitHub Actions запускает Android APK. Тесты расчётов и навигации выполняются перед Gradle. После сборки отдельная задача устанавливает этот же APK в эмулятор Android 15 и проверяет холодный запуск в авиарежиме, мастерскую, калькулятор, системное «Назад» и перезапуск. В артефакте Restoration-apk находится файл Restoration.apk. Распакуйте ZIP на телефоне и откройте APK. При запросе Android разрешите установку приложению, из которого открыли файл. Для существующей установки выберите «Обновить». Если Android отклоняет обновление, сохраните текущую установку с её данными.

Для подписанной сборки используются прежние RC_KEYSTORE_BASE64, RC_KEYSTORE_PASSWORD и alias restoration. Идентификатор приложения com.restoration.calc и прежняя схема versionCode сохраняются. Без ключа workflow выдаёт debug APK. Его подпись отличается от release. Публикация в Releases запускается отдельно вручную.

## Проверка на телефоне

1. Включите авиарежим перед первым запуском. Проверьте «Сегодня», текущий стол, ближайший выезд и карточку цели.
2. Откройте «Объекты», выберите «В плане», откройте лестницу. Проверьте жест «Назад».
3. В «Мастерской» откройте абразивы через фильтр «Расходники». В «Прогрессе» откройте объект, давший пример выручки.
4. Смените тему в правом верхнем углу. Закройте и запустите приложение снова.
5. В калькуляторе проверьте свой черновик и список заказов. Для проверки формулы используйте отдельный тестовый расчёт на 2000 × 1000 мм без кромок и услуг. Площадь составит 2 м². После включения сети вход Google доступен в настройках калькулятора.

## Устройство прототипа

- mobile/ содержит самостоятельные экраны, компоненты, локальные иллюстрации и демонстрационную модель. Экраны не записывают рабочие события, склад или финансы. В локальном хранилище добавляется только workshop.theme.v1.
- scripts/copy-web.mjs собирает www/ из mobile/ и исходных js/, css/, icons/, fonts/. Формулы, Firebase SDK, прежний UI и формат заказов используются непосредственно из Android-ветки. Статический сайт в корне собирается и работает как прежде.
- calculator.html открывается в том же основном WebView и origin. Сохраняются доступ к нативному Google-входу, прежним rc.* ключам и базе Firestore. Для старых установок локальный sw.js снимает регистрацию кэширующего сервис-воркера сайта.
- Локально из android-app/: npm ci, npm test, npm run sync. Для теста интерфейса нужен Chrome/Chromium (можно указать CHROME_BIN). Для Gradle нужны JDK 21 и Android SDK 35.
- Следующий этап — привязка объекта к существующему заказу и журнал событий выезда с восстановлением после перезапуска. Перед записью реальных событий нужны проверенные экспорт, локальное транзакционное хранилище и правила синхронизации.
